# 🛒 E-Commerce App

A modern and responsive e-commerce web application built with React, Vite, and Tailwind CSS.

## ✨ Features

- 🔐 User Authentication
- 🛍️ Browse Products
- 🔎 Product Search
- 🛒 Shopping Cart
- 💳 Checkout Page
- 📱 Responsive Design

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- React Router
- JavaScript (ES6+)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/AbuMotlaq/E-Commerce.git
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

The application will run on:

```
http://localhost:5173
```
